# 🚀 Деплой Eysk-telegram-bot на JustRunMy.App

## 📋 Шаг 1: Регистрация на JustRunMy.App

1. Открой https://justrunmy.app/
2. Нажми **"Sign Up"** или **"Get Started"**
3. Зарегистрируйся используя email: **denisturkey007@gmail.com**
4. Подтверди email (проверь почту)

## 📦 Шаг 2: Подготовка репозитория

Все файлы уже готовы в репозитории:
- ✅ `Dockerfile` - создан
- ✅ `.dockerignore` - создан
- ✅ `requirements.txt` - готов

## 🔧 Шаг 3: Создание приложения

1. После входа в JustRunMy.App, нажми **"New App"** или **"Create Application"**

2. Выбери **"Import from GitHub"**:
   - Авторизуй доступ к GitHub
   - Выбери репозиторий: `Denis-Shev777/eysk-telegram-bot`
   - Branch: `claude/add-stars-usdt-payments-P2qS2` (или `main`)

3. Настройки деплоя:
   - **Name**: `eysk-telegram-bot`
   - **Region**: выбери ближайший (Europe если есть)
   - **Build Method**: Docker (должен определиться автоматически)

## 🔐 Шаг 4: Переменные окружения

В разделе **"Environment Variables"** добавь:

```
BOT_TOKEN=твой_токен_бота_от_BotFather
ADMIN_ID=твой_telegram_id
PAYMENT_CARD=номер_карты_для_оплаты
PAYMENT_RECIPIENT=получатель_платежа
USDT_WALLET=0x97aa6013580c4f34fae3f7b4f42c176e9bd0ac7c
```

### Как получить переменные:

**BOT_TOKEN:**
- Открой Telegram
- Найди @BotFather
- Используй команду `/mybots` → выбери бота → API Token

**ADMIN_ID:**
- Открой Telegram
- Найди @userinfobot
- Отправь ему `/start`
- Скопируй свой ID

**PAYMENT_CARD и PAYMENT_RECIPIENT:**
- Твои данные для приема оплаты картой

## 💾 Шаг 5: Настройка Persistent Storage (ВАЖНО!)

JustRunMy.App должен сохранять базу данных SQLite между перезапусками:

1. В настройках приложения найди раздел **"Volumes"** или **"Storage"**
2. Создай persistent volume:
   - **Mount Path**: `/app/data`
   - **Size**: 100 MB (достаточно)

3. Если нет опции Volumes, проверь что база создается в `/app/` (по умолчанию так и есть)

## 🚀 Шаг 6: Деплой!

1. Нажми **"Deploy"** или **"Create App"**
2. Подожди 2-5 минут пока соберется Docker образ
3. Проверь логи:
   - Должна появиться надпись: `"Bot started successfully"`
   - Не должно быть ошибок про BOT_TOKEN

## ✅ Шаг 7: Проверка работы

1. Открой Telegram
2. Найди своего бота (тот, чей TOKEN ты указал)
3. Отправь `/start`
4. Бот должен ответить приветственным сообщением

## 📊 Мониторинг ресурсов

Проверь потребление ресурсов в Dashboard:
- **RAM**: должно быть ~80-120 MB (лимит 256 MB)
- **CPU**: ~10-20% (лимит 15%)
- **Disk**: ~50-100 MB (лимит 300 MB)

Если RAM превышает 200 MB - напиши мне!

## 🆘 Решение проблем

### Проблема: "Build failed"
**Решение**: Проверь что Dockerfile в корне репозитория

### Проблема: "Application crashed"
**Решение**: Проверь логи, скорее всего не хватает переменной окружения

### Проблема: Бот не отвечает
**Решение**:
1. Проверь логи приложения
2. Убедись что BOT_TOKEN правильный
3. Проверь что приложение запущено (статус "Running")

### Проблема: База данных стирается при перезапуске
**Решение**:
1. Настрой Persistent Volume (см. Шаг 5)
2. Или измени путь к БД в `database.py` на `/app/data/users.db`
